# Cracks and Potholes in Road Images

## Overview

Cracks and Potholes in Road Images is a segmentation package built from multiclass distress masks.

- Task: segmentation
- Images: 2235
- Annotations: 165863
- Classes: 2 (crack, pothole)
- Annotation format: paired PNG masks

## Source Dataset

- Source repository: https://github.com/biankatpas/Cracks-and-Potholes-in-Road-Images-Dataset
- Project page: https://biankatpas.github.io/Cracks-and-Potholes-in-Road-Images-Dataset/
- Mendeley record: https://data.mendeley.com/datasets/t576ydh9v8/4
- DOI: 10.17632/t576ydh9v8.4

## Notes

- The source dataset contains 2,235 road images (`1024x640` and `1024x630`) captured between 2014 and 2017 by Highway Diagnostic Vehicles of the Brazilian National Department of Transport Infrastructure (DNIT) across federal highways in Espírito Santo, Rio Grande do Sul, and the Federal District.
- Each image in the source release is accompanied by binary PNG masks for the road region, cracks, and potholes (`164,388` connected crack components and `1,475` connected pothole components across `2,233` images with distress annotations).
